# Milvus — base vectorielle pour l’IA / AI Vector Database

## Français

Milvus est une base vectorielle pour stocker des embeddings et effectuer des recherches de similarité à grande échelle.

### À quoi ça sert ?

Elle peut retrouver des éléments proches d’un vecteur de requête, par exemple pour une recherche sémantique ou un système RAG.

### Exemple

Encoder des documents, enregistrer leurs vecteurs et métadonnées, puis rechercher les passages proches d’une question.

Ce dépôt a actuellement un README minimal. Consulter la documentation officielle pour l’installation et les versions.

## English

Milvus is a vector database for storing embeddings and running similarity search at scale.

### What is it for?

It can retrieve items close to a query vector, for example in semantic search or a RAG system.

### Example

Encode documents, store their vectors and metadata, then search for passages close to a query.

This repository currently has a minimal README. Consult the official documentation for installation and versions.
